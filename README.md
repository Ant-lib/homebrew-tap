# Ant-lib Homebrew tap

```sh
brew tap ant-lib/tap
brew install --cask ant-lib/tap/hingewave
```

Homebrew 6 and later ask you to trust third-party taps first: `brew trust ant-lib/tap`. Hingewave is ad-hoc signed and not notarized; the cask clears the quarantine flag after install so the first launch is not blocked.
